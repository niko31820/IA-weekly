# IA-weekly

Une veille des usages de l’IA pour gagner du temps, découvrir des possibilités inattendues et mieux exploiter Hermes / Trinity.

**Lire le numéro 001 : https://niko31820.github.io/IA-weekly/**

- Source éditoriale : `editions/001.md`.
- Recréer la page : `python -m pip install -r requirements.txt` puis `python build.py`.
- Publication GitHub Pages depuis `main`, répertoire racine.
- Aucune programmation hebdomadaire activée.
